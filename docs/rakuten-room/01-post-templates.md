# 投稿文の型：商品を説明しない。困り事と「その先」を書く

---

## 大前提：ROOMは最初の2行しか読まれない

商品コメントは長く書けるが、タイムライン上で見えるのは**冒頭2〜3行**。
続きは「もっと見る」を押した人しか読まない。

したがって構造はこうなる。

```
1行目 ← ここで「私のことだ」と思わせる（勝負の9割）
2行目 ← 放置したときの実害を1つだけ、具体的に
──── ここから先は押した人しか読まない ────
3行目以降 ← 実害の追撃 → 転換 → 使用イメージ → 今買う理由 → タグ
```

---

## 型①「未来分岐型」（メインで使う型）

これが「こんな困り事を解決できる／でもやらないとどうなるか」を成立させる型。

```
【1】名指し（誰の・いつの・どの場面の困り事か）     ※30字以内・体言止めか問いかけ
【2】放置の実害①（数字で）                        ※金額・時間・回数・頻度のどれか
【3】放置の実害②（感情で）                        ※恥ずかしい／後戻りできない／家族に言われる
【4】転換（「これ1つで終わる」）                   ※説明ではなく“終わる”という宣言
【5】使用イメージ（動作を1つだけ）                 ※「貼るだけ」「入れるだけ」「置くだけ」
【6】自分の事実（感想型）                          ※「うちでは◯週間〜」体験ベース
【7】今買う理由（セール／季節／在庫）
【8】ハッシュタグ 5〜8個
```

### 記入例（テンプレそのまま）

```
排水口のヌメリ、今週も見なかったことにした人へ。

放置すると、年末の大掃除でハイターと格闘する2時間がそのまま予約される。
しかも夏より冬のほうがニオイは上がってくる。気づくのはたいてい来客の5分前。

これは、月1で置くだけ。
ゴミ受けの上にポンと入れて、あとは忘れていい。

うちは3か月続けて、あのヌメリ掃除を1回もしていない。
スーパーSALEで買い置きしておくと来年の春まで持ちます。

#排水口 #ヌメリ取り #大掃除しない暮らし #時短家事 #楽天ROOM
```

## 実害の作り方：4方向のどれかを必ず入れる

「放置したらどうなるか」が思いつかないときは、この4つに当てはめる。

| 方向 | 問い | 例 |
|---|---|---|
| 💰 お金が減る | 買い直し・電気代・修理代はいくら？ | 「結露を放置した壁紙の張り替えは1面◯万円」 |
| ⏳ 時間が消える | 毎日何分 × 365日？ | 「1日5分の探し物は、年で30時間」 |
| 👀 人に見られる | 来客・職場・写真に写る？ | 「玄関のニオイは、住んでる人だけ気づかない」 |
| 🚪 後戻りできない | 傷む・カビる・歪む・今しかない | 「ニットは一度伸びたら戻らない」 |

**コツ：実害は「大惨事」ではなく「小さくて確実に起きること」を書く。**
大げさな煽りは規約（誇大表現）に触れるうえ、読み手に嘘だとバレる。
効くのは「たしかに毎年それ、やってる」の一撃。

## 型②「3秒共感型」（軽い商品・単価が低いもの）

```
【1】あるある一言（?で終える）
【2】原因が自分のせいじゃないと言ってあげる
【3】解決を一言
【4】タグ
```

```
洗濯物、部屋干しの日だけ臭いません？

それ、干し方じゃなくて洗濯槽のほうだったりします。

つけ置き1回で、次の部屋干しからニオイが戻らなくなった。
雨が続く前に1箱。

#部屋干し #生乾き臭 #洗濯槽クリーナー #梅雨じゃなくても #楽天ROOM
```

---

## 型③「損失回避・締切型」（セール期に強い）

```
【1】締切の提示（季節・セール・在庫）
【2】その締切を逃したときに起きること
【3】解決
【4】今日中に、を一言
```

```
寒くなってから買うと、だいたい売り切れてます。

去年の11月、足元ヒーターを探して3店舗ハシゴして、結局あきらめた。
で、1月の電気代を見て後悔した。暖房を強くしていた分です。

先に足元だけ温めるほうが、部屋ごと温めるより安い。
マラソン中に確保しておくやつ。

#足元ヒーター #電気代節約 #冷え対策 #冬支度 #楽天ROOM
```

## 1行目のストック（そのまま使える冒頭30パターン）

**名指し系**
1. ◯◯、今週も見なかったことにした人へ。
2. これ、共働きの家だと絶対に起きます。
3. 賃貸の狭い洗面所、ここが限界だと思ってました。
4. 小学生の子がいる家の玄関、だいたいこうなる。
5. 一人暮らし3年目で、やっと原因がわかった。

**問いかけ系**
6. ◯◯、いつから放置してます？
7. 毎朝これに何分使ってるか、数えたことあります？
8. 来客の5分前に焦るの、そろそろやめません？
9. それ、掃除じゃなくて「予防」で消えるって知ってました？
10. 洗ってるのに臭う日、ありません？

**告白系（感想型・ROOM上位が使う型）**
11. 買い直したのは、結局これだけでした。
12. 3年迷って買って、もっと早く買えばよかった枠。
13. 正直、効果ないと思ってました。
14. これに変えてから、あの家事が消えました。
15. 去年サボって、今年の冬に請求が来ました。

**数字系**
16. 1日5分の◯◯は、1年で30時間です。
17. 500円をケチって、◯万円の修理になった話。
18. 電気代、去年の同じ月と比べたら◯円違いました。
19. 3か月、まだ1回も掃除してません。
20. 買い替え3回目でようやく正解に着いた。

**逆説系**
21. 掃除グッズを増やすと、掃除は減りません。
22. 収納を買う前に、これを1個。
23. 高い洗剤より、先にこっちでした。
24. 便利グッズはだいたい邪魔になる。これ以外は。
25. 安いほうを買って、結局2回買いました。

**季節の締切系**
26. 寒くなってから買うと、だいたい売り切れてます。
27. 結露が出てからでは、もう遅い場所があります。
28. 衣替えの前日に後悔するやつ。
29. 大掃除の日に泣かないための、9月の1個。
30. ふるさと納税、12月31日に慌てる人へ。

## 書いたあとの自己チェック（投稿前に必ず）

- [ ] 1行目に**商品名が入っていない**（入れるのは困り事）
- [ ] 「放置したらどうなるか」が**具体的な数字か情景**になっている
- [ ] 効果を**断定していない**（治る・効く・改善・絶対・No.1 を検索して確認）
- [ ] 自分が使っていない商品に「使ってます」と書いていない
- [ ] 使い方の動作が**1つだけ**書いてある（貼る／置く／入れる）
- [ ] 今買う理由が1行ある
- [ ] ハッシュタグに「悩みワード」が入っている（商品名だけにしない）

---

## ハッシュタグの考え方

検索されるのは商品名ではなく**悩み**。3層で組む。

```
悩みワード（2〜3個）  #生乾き臭 #排水口のヌメリ #足元が冷える
属性ワード（2個）      #共働き主婦 #狭い賃貸 #小学生ママ
汎用ワード（2個）      #楽天ROOM #楽天お買い物マラソン #買ってよかった
```
