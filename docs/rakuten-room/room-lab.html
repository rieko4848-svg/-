商品選定の3条件

FILTER

A｜解決型であること

判定の問いはひとつ。「これを買わないと、来週どんな小さな損をする？」に一言で答えられるか。答えられない商品は投稿しない。ここがいちばん硬いフィルタです。

B｜すでにROOMでコレされていること

コレ数が多い＝ROOM内で露出しやすく、実売の証拠もある。ただし超定番は埋もれます。狙い目はコレ数が数百〜数千台で伸びている最中のもの、またはコレ数は中くらいなのにレビューが多く★4以上のもの。

C｜価格と料率のバランス

月1万円までは1,000〜5,000円の消耗品・日用品で回転数を稼ぐ。そのうえで料率アップ商品を月10本だけ混ぜる。高額家電は単発では当たるが安定しないので軸にしない。

週1・30分のリサーチ

ROUTINE
  1. ROOMコレ数ランキングを上から50件。「解決型」だけメモ（目安10件）
  2. 楽天市場側で料率とレビュー数・★を確認。料率3%以下かつレビュー100件未満は捨てる
  3. 残りに「放置したらどうなる？」を1行書く。書けないものは捨てる
  4. 残ったものが今週の投稿候補（5〜8件で十分）
  5. 料率アップショップから、季節の困り事に当たるものを2件だけ拾う

1日の配分

解決型（本命・力を入れて書く）毎日1件 ／ オリジナル写真の投稿 週1件以上 ／ 余力があれば定番か料率アップを+1〜2件。1日3投稿を超えない。

多く投稿するほど負ける

FREQUENCY

ここは直感と逆です。量を打つと、1件ずつの反応が育つ前に流れていきます。

通算20,000投稿という天井があります。1日50件打つと1年で使い切る。雑な投稿でこの枠を消費するのが、いちばんもったいない負け方です。

頻度より効くレバー

×5.8

自分で撮った写真の投稿は、商品ページの写真を使った通常投稿の
5.8倍、売上が発生しやすい。

CランクからBランクに上がる条件が、そもそもオリジナル写真の投稿（推奨は週1以上）。ランクB以上でランクボーナスが付きます。だから優先順位はこうなります。

  1. オリジナル写真 週1（→Bランク＝ボーナス＋5.8倍）
  2. 解決型の投稿文 毎日1件（→クリックと成約）
  3. 投稿数を増やす（←最後。ここから始めると伸びない）

自分が実際に買った商品を、明るい場所で1枚撮るだけ。この写真と「困り事→放置したらどうなるか」の文章が組み合わさったとき、体験談の説得力が別物になります。

なおAランクの目安は月間1,500〜2,000クリック以上（1日50〜70クリック）。売上額ではなく「楽天市場へ何人送ったか」で見られています。

報酬が発生する条件

24H / 89D

リンクがクリックされ → 24時間以内にカゴに入り → 89日以内に購入されると報酬。

勝負はクリックから24時間。ここでカゴに入らないと消えます。だからセール前日の夜〜当日朝に投稿を寄せるのが効く。逆に、カゴにさえ入れば購入が3か月先でも拾えます。

直し方は2つだけ

IMPROVE

クリックが少ない → 商品選定と1行目が悪い。型を替えて再投稿。
クリックは多いが売れない → 実害の描写（2〜3行目）が弱い。数字を入れる。

越えてはいけない線

COMPLIANCE

「放置したらどうなるか」を書く手法は、やりすぎると誇大表現として規約違反になります。アカウント停止に直結するので、言い換えを習慣にしてください。

使わないこう書く
花粉症が治る朝の掃除が1回で終わるようになった
効果絶大うちでは3週間ニオイが戻っていない
No.1の吸水力レビュー◯件で★4.6（2026年◯月時点）
絶対買うべき買い直したのはこれだけ
冷え性が改善する足先が冷たくて眠れない夜が減った（個人の感想）

ほかに禁止：自己購入による報酬取得（セルフアフィリエイト）、根拠のない「限定」「ここだけ」、使っていない商品の体験談。
