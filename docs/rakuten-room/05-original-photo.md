# オリジナル写真が承認されない原因

自分で撮った写真を載せても、`#オリジナル写真` として認定されないケース。
ランクB昇格と売上5.8倍がここにかかっているので、最優先で潰す。

---

## まず確認：投稿を開いて、タグが **青字** になっているか

> 正しく付いていると **「#オリジナル写真」が青字（リンク）になる。**
> 黒いままなら、ハッシュタグとして認識されていない。

これだけで原因の大半が特定できる。

---

## 原因① 全角の「＃」を使った（最頻出）

- **全角＃** … `＃オリジナル写真` → ハッシュタグとして認識されない → **審査対象外**
- **半角#** … `#オリジナル写真` → 青字になる → 審査される

日本語入力のまま打つと全角になりやすい。**ここが圧倒的に多い失敗**。

## 原因② タグを付け忘れた／後から付けた

- 投稿時に付いていないとダメ
- **後から付け足しても審査の対象にならない**（何日待っても認定されない）
- 直す方法は**削除して新規投稿し直す**しかない

## 原因③ 商品が楽天で買えるものと同一でない

- 色違い・サイズ違い・**パッケージ違い**（リニューアル前後など）はNG
- 手持ちの品とリンク先の商品がズレていないか確認する

## 原因④ 商品がはっきり写っていない

- ピンぼけ／暗い
- **他の商品が写り込んでいる**（並べ撮り、背景に別ブランドなど）
- 引きすぎて何の商品か分からない

## 原因⑤ 著作権・肖像権にかかるもの

審査対象にならない場合がある：

- **書籍の表紙・中身**（本はオリジナル写真NG）
- CDジャケット、ゲームソフト、ポスター、テレビ画面
- キャラクターグッズ
- 有名人が写っているもの

## 原因⑥ 楽天で買える商品が写っていない

風景だけ、手元だけ、雰囲気写真だけ、はガイドライン違反。
**紹介している商品そのものが写っていること**が条件。

## 原因⑦ まだ審査中

- 反映まで**数日かかる**ことがある（早ければ翌日、3日は様子を見る）
- 月末ぎりぎりに投稿すると、その月のランク判定に間に合わない
  → **月末の5日前まで**に投稿しておく

---

## 投稿前チェックリスト

- [ ] `#` は**半角**で打った
- [ ] 投稿画面で `#オリジナル写真` が**青字**になっている
- [ ] 投稿と**同時に**タグを付けた（後付けではない）
- [ ] 紹介する商品**そのもの**が、はっきり大きく写っている
- [ ] 他の商品が写り込んでいない
- [ ] リンク先の商品と**色・サイズ・パッケージが一致**している
- [ ] 本・CD・キャラクター・人物が写っていない
- [ ] 明るい場所で撮った
- [ ] 月末5日前までに投稿した

---

## 注意

**オリジナル写真の審査結果について、個別の問い合わせには対応していない。**
理由は教えてもらえないので、上のチェックリストで自己診断するしかない。

だからこそ、**投稿前に潰す**のが唯一の方法になる。
