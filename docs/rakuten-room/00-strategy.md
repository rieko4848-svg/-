# 楽天ROOM 収益化戦略メモ

最終更新: 2026-09-12

---

## 0. 前提：どこで報酬が決まるか

| 要素 | 内容 |
|---|---|
| 通常報酬 | 購入額の 2〜4%（ジャンル別。ファッション/食品/コスメ/スポーツ ≒4%、キッチン/日用雑貨/おもちゃ ≒3%） |
| ROOMランクボーナス | 最大 +3% |
| 料率アップ商品 | ショップ側の設定で最大 20%。**1商品あたりの報酬上限なし** |
| 成果の発生条件 | 自分のリンク経由のクリック後、期限内に楽天市場で購入されたもの（クリックした商品以外の購入も一部成果になる） |

**結論:** 「3%の商品を100個売る」より「20%の商品を15個売る」ほうが速い。
ジャンル選びより先に **料率** を見る癖をつける。

## 1. 商品選定の3条件（この順で絞る）

やりたいことが「今、問題を解決できるもの × ROOMでたくさんコレされているもの」なので、
選定は次の3つのANDで判断する。

### 条件A：解決型であること（＝買う理由に締切がある）
- ✅ 「困っている」→「今すぐ終わらせたい」もの（排水口のヌメリ、結露、部屋干し臭、足元の冷え、断線するケーブル）
- ❌ 「素敵」「いつか欲しい」もの（インテリア雑貨、おしゃれ小物）は保存されるが売れにくい
- 判定の問い：**「これを買わないと、来週どんな小さな損をする？」に一言で答えられるか**
  - 答えられない商品は投稿しない。これが本戦略のいちばん硬いフィルタ。

### 条件B：ROOM内ですでにコレされていること
- 確認先 → **ROOM「コレ数ランキング」** https://room.rakuten.co.jp/discover/collectItemRank
- コレ数が多い ＝ ROOM内の検索・発見面に露出しやすく、実売の証拠もある
- ただし **コレ数が多すぎる超定番は埋もれる**。狙い目は
  - コレ数 数百〜数千台で **伸びている最中**のもの
  - コレ数は中くらいだが **レビュー数が多く★4以上**のもの（＝ROOM内競合は薄いのに市場では売れている）
- 補助の確認先
  - 楽天市場 デイリー/リアルタイムランキング（ジャンル別）https://ranking.rakuten.co.jp/
  - ROOM「見つける」の特集・隠れヒット商品ページ

### 条件C：価格と料率のバランス
- 初期（月1万円まで）：**1,000〜5,000円の消耗品・日用品**を軸に回転数を稼ぐ
- 中期：料率アップ商品（5〜20%）を月10本だけ混ぜる。ここが利益の源泉
- 高額家電は単発では当たるが安定しない。軸にしない

## 2. 毎週のリサーチ手順（30分 × 週1）

1. **コレ数ランキング**を上から50件スクロール。「解決型」だけメモ（目安10件）
2. 各商品を楽天市場側で開き、**料率**とレビュー数・★を確認
   - 料率3%以下 かつ レビュー100件未満 → 捨てる
3. 残った商品に対して **「放置したらどうなる？」を1行**書く（書けないものは捨てる）
4. 残ったものが今週の投稿候補（5〜8件あれば十分）
5. 同時に「料率アップショップ」一覧 https://affiliate.rakuten.co.jp/recommend/uplist/ を見て、
   高料率の中から**季節の困り事に当たるもの**を2件だけ拾う

### 投稿の配分（1日3〜5投稿するなら）
- 解決型（本命・力を入れて書く）… 2件
- コレ数ランキング上位の定番（露出稼ぎ）… 2件
- 料率アップ商品（利益）… 1件

## 3. 伸びる／伸びないの分岐点

| 効く | 効かない |
|---|---|
| テーマを1本に絞る（例：共働き・小2の母の時短、狭い賃貸の湿気対策） | 何でも屋のROOM |
| 自分で使った**感想型**のコメント（上位ランクほどこの型） | 商品説明のコピペ |
| 1枚目の写真が明るい商品を選ぶ | 暗い・生活感のある写真の商品 |
| セール期（5・0のつく日、マラソン、SALE）に投稿を寄せる | 平日深夜に量だけ投げる |
| クリックは多いが売れない投稿の**コメントを書き直す** | 投稿しっぱなし |
| 他ユーザーへのいいね回り（発見されるための導線） | フォロー返し狙いだけの無差別フォロー |

**分析の起点はこの2つだけ:**
- クリックが少ない → 商品選定と1行目が悪い
- クリックは多いが売れない → 紹介文の後半（実害の描写と背中押し）が弱い

## 4. 越えてはいけない線（アカウント停止に直結）

投稿文の狙いが「放置したらどうなるか」を想像させる方向なので、ここは毎回チェックする。

- ❌ 薬機法：「治る」「効く」「改善する」「痩せる」「アレルギーが治まる」
  → 化粧品・健康食品・健康器具・ペット用品で特に厳しい
- ❌ 景表法：「No.1」「絶対」「必ず」「日本一」（根拠のない最上級・断定）
- ❌ 根拠のない「限定」「ここだけ」「今だけ」
- ❌ 自己購入による報酬取得（セルフアフィリエイト）
- ❌ 事実と違う体験談（使っていないのに「使ってます」）

### 安全な言い換え
| NG | OK |
|---|---|
| 花粉症が治る | 朝の掃除が1回で終わるようになった |
| 効果絶大 | うちでは3週間ニオイが戻っていない |
| No.1の吸水力 | レビュー◯件で★4.6（2026年◯月時点） |
| 絶対買うべき | 買い直したのはこれだけ |
| 冷え性が改善 | 足先が冷たくて眠れない夜が減った（個人の感想） |

**原則：効果を断定せず、自分の生活で起きた変化を事実として書く。**
これは規約対策であると同時に、いちばん売れる書き方でもある。
