# 楽天ROOM 収益化戦略メモ

最終更新: 2026-09-12

---

## 0. 前提：どこで報酬が決まるか

| 要素 | 内容 |
|---|---|
| 通常報酬 | 購入額の 2〜4%（ジャンル別。ファッション/食品/コスメ/スポーツ ≒4%、キッチン/日用雑貨/おもちゃ ≒3%） |
| ROOMランクボーナス | 最大 +3% |
| 料率アップ商品 | ショップ側の設定で最大 20%。**1商品あたりの報酬上限なし** |
| 成果の発生条件 | 自分のリンク経由のクリック後、期限内に楽天市場で購入されたもの（クリックした商品以外の購入も一部成果になる） |

**結論:** 「3%の商品を100個売る」より「20%の商品を15個売る」ほうが速い。
ジャンル選びより先に **料率** を見る癖をつける。

## 1. 商品選定の3条件（この順で絞る）

やりたいことが「今、問題を解決できるもの × ROOMでたくさんコレされているもの」なので、
選定は次の3つのANDで判断する。

### 条件A：解決型であること（＝買う理由に締切がある）
- ✅ 「困っている」→「今すぐ終わらせたい」もの（排水口のヌメリ、結露、部屋干し臭、足元の冷え、断線するケーブル）
- ❌ 「素敵」「いつか欲しい」もの（インテリア雑貨、おしゃれ小物）は保存されるが売れにくい
- 判定の問い：**「これを買わないと、来週どんな小さな損をする？」に一言で答えられるか**
  - 答えられない商品は投稿しない。これが本戦略のいちばん硬いフィルタ。

### 条件B：ROOM内ですでにコレされていること
- 確認先 → **ROOM「コレ数ランキング」** https://room.rakuten.co.jp/discover/collectItemRank
- コレ数が多い ＝ ROOM内の検索・発見面に露出しやすく、実売の証拠もある
- ただし **コレ数が多すぎる超定番は埋もれる**。狙い目は
  - コレ数 数百〜数千台で **伸びている最中**のもの
  - コレ数は中くらいだが **レビュー数が多く★4以上**のもの（＝ROOM内競合は薄いのに市場では売れている）
- 補助の確認先
  - 楽天市場 デイリー/リアルタイムランキング（ジャンル別）https://ranking.rakuten.co.jp/
  - ROOM「見つける」の特集・隠れヒット商品ページ

### 条件C：価格と料率のバランス
- 初期（月1万円まで）：**1,000〜5,000円の消耗品・日用品**を軸に回転数を稼ぐ
- 中期：料率アップ商品（5〜20%）を月10本だけ混ぜる。ここが利益の源泉
- 高額家電は単発では当たるが安定しない。軸にしない

## 2. 毎週のリサーチ手順（30分 × 週1）

1. **コレ数ランキング**を上から50件スクロール。「解決型」だけメモ（目安10件）
2. 各商品を楽天市場側で開き、**料率**とレビュー数・★を確認
   - 料率3%以下 かつ レビュー100件未満 → 捨てる
3. 残った商品に対して **「放置したらどうなる？」を1行**書く（書けないものは捨てる）
4. 残ったものが今週の投稿候補（5〜8件あれば十分）
5. 同時に「料率アップショップ」一覧 https://affiliate.rakuten.co.jp/recommend/uplist/ を見て、
   高料率の中から**季節の困り事に当たるもの**を2件だけ拾う

### 投稿の配分
**1日1〜3投稿。** 配分は日替わりでいい。
- 解決型（本命・力を入れて書く）… 毎日1件
- オリジナル写真の投稿（後述。最重要）… 週1件以上
- コレ数ランキング上位の定番 or 料率アップ商品 … 余力があれば+1〜2件

## 2-B. 投稿頻度：多いほうが負ける

ここは直感と逆になる。**量を打つと、1件ずつの反応が育つ前に流れていく。**

### 実際のペース

| 項目 | 数字 |
|---|---|
| 推奨ペース | **1日1投稿が基本**。伸びる型が固まっても**最大3投稿**まで |
| 質と量 | 1日5件の丁寧な投稿 ＞ 1日100件の雑な投稿 |
| システム上限 | 1時間100件 ／ 24時間200件 ／ アカウント通算20,000件 |
| 副業での推奨 | 上限の**3割以下**で運用 |
| いいね | 一度に200回で打ち止め・約1時間で再開。1日900回程度 |
| フォロー | 一度に100回で打ち止め・約1時間で再開 |

**通算20,000投稿という天井があることに注意。** 1日50件打つと1年で使い切る。
雑な投稿でこの枠を消費するのは、いちばんもったいない負け方。

### 実績として公開されているペース

| 活動量 | 到達 |
|---|---|
| 1日1投稿＋フォロー回り200＋いいね回り上限 | 13か月目で**月2万円** |
| （別の人）3か月目 | Aランク到達・**月19,348円** |
| 同じ人・7か月目 | **月41,630円** |
| 初報酬まで | 最低1か月。2か月目以降から安定しやすい |

差が大きいのは活動量ではなく、**テーマの絞り方とオリジナル写真の有無**。

### 現実的な分布

100人アンケートでは **Aランクは約3%**。そのAランク層の月収が
「5,000円未満〜3〜5万円」。つまり上位3%に入っても月数万円の世界。
**月10万円は例外値であって目標値ではない。**
月1〜3万円を1年かけて取りにいく設計が正しい。

## 2-C. 頻度より効くレバー：オリジナル写真

調べていてこれがいちばん大きい数字だった。

> **自分で撮った写真の投稿は、通常投稿（商品ページの写真）の 5.8倍 売上が発生しやすい。**

- CランクからBランクに上がる条件が、そもそも**オリジナル写真の投稿**
- 推奨頻度は**週1投稿以上**
- ランクB以上でROOMランクボーナス（最大+3%）が付く

**つまり優先順位はこうなる。**
1. オリジナル写真 週1（→Bランク＝ボーナス＋5.8倍）
2. 解決型の投稿文 毎日1件（→クリックと成約）
3. 投稿数を増やす（←最後。ここから始めると伸びない）

自分が実際に買った商品を、明るい場所で1枚撮る。それだけでいい。
今回の「困り事→放置したらどうなるか」の文章は、この自分の写真と組み合わせたときに
いちばん効く（写真が自分のものだと、体験談の説得力が別物になる）。

### Aランクの目安
- 月間 **1,500〜2,000クリック以上**（＝1日50〜70クリック）
- 売上額ではなく「楽天市場へ何人送ったか」で見られている

## 2-E. フォロー回り・いいね回りは、どこまで必要か

いちばん消耗するのがここ。結論から言うと、**毎日やるのは義務ではない。**

### ランク維持の条件としては「3か月に1回」で足りる

- ランク判定における**検索・フォロー・いいね**は、**3か月に1回で条件達成**
- ランクB以上をキープする主条件は、フォロー回りではなく**オリジナル写真の投稿数**
- つまり「毎日200フォロー」はランクのために必要な作業ではない

### では毎日のいいね回りは何なのか → 集客施策

義務ではなく、**自分のROOMを見てもらうための導線**。だから効果には個人差がある。

- いいね回りをしていない**Aランクの人もいる**
- 逆にいいね回りとゼロコレで伸ばす人もいる
- **放置中のユーザーをフォローしても意味がない**（見に来ないので）

**判断基準：** 続かない量を毎日やるくらいなら、続く量に削って
オリジナル写真（5.8倍）に時間を回すほうが期待値が高い。

### やりすぎは逆にアカウントが飛ぶ

- 短時間に大量のいいねは**機械的とみなされ、アカウント削除のリスク**（2023年以降厳しくなっている）
- 自動化ツールは規約違反。使わない

### 効率の順番（上から優先）

1. **いいね返し** — 自分にいいねをくれた人に返す。**相手が確実にアクティブ**なので最も効率がいい
2. **前日に自分がコレした商品へいいねをくれた人** に、古い順から返す
3. **ランキング上位（1〜50位）のルーマー** への挨拶いいね
4. **空白検索**で出てくるアクティブユーザー
5. ❌ 無差別フォロー（放置アカウントに当たるので時間の無駄）

### 1日10分の最小ルーティン

| 頻度 | やること | 目安 |
|---|---|---|
| 毎日 | **いいね返しだけ** | 5〜10分 |
| 週1 | ランキング上位50人へ挨拶いいね | 10分 |
| 週1 | オリジナル写真を1枚撮って投稿 | 10分 |
| 3か月に1回 | 検索・フォロー・いいねを1セット（ランク条件クリア用） | 15分 |

これで**週あたり1時間半**。参考までに、フォロー回り200＋いいね上限まで毎日回した人が
13か月目で月2万円。活動量を積んでも到達はその程度なので、
**削って続けるほうが合理的**という判断になる。

## 2-F. 既存投稿の扱い（編集できるもの・できないもの）

過去のコレは資産。ただし**後から直せるものと、直せないものがある**。

| 項目 | 後から直せるか |
|---|---|
| 商品紹介文（コメント） | ✅ できる |
| ハッシュタグ | ✅ できる |
| **#オリジナル写真** | ❌ **できない** |

### 紹介文の直し方
`My ROOM` → 商品をタップ → `さらに見る` → 商品写真の右下 `編集・削除`

### #オリジナル写真の落とし穴（重要）

> 後から `#オリジナル写真` を付けても**審査の対象にならず、オリジナル写真として認められない。**
> 付け忘れた場合は、**投稿を削除して新規投稿し直す**しかない。

売上5.8倍・ランクBの条件がこれなので、**撮った写真を上げるときは必ずその場でタグを付ける**。
ここだけは取り返しがつかない。

## 2-G. 数字の見方（何が見られて、何が見られないか）

### 見られるもの
`My ROOM` → `設定（⚙）` → `売上確認` → **楽天アフィリエイトレポート**
- 売上額 / 報酬 / **クリック数** / 売上件数 / CVR

### 見られないもの
- **投稿1件ごとのクリック数は見られない**

ただし**ショップ名単位では見られる**ので、投稿時にショップ名を入れておくと、
あとからROOM内をショップ名で検索して「どの系統が効いたか」を追える。

### クリック数だけで診断が分岐する

| クリック | 読み取り | 直す場所 |
|---|---|---|
| ほぼゼロ | 見られていない | 露出。テーマの一貫性・タグ・オリジナル写真 |
| ある程度あるのに成果ゼロ | 見られたが買う理由が伝わっていない | 紹介文。とくに実害の描写と背中押し |

**投稿数を増やすのは、どちらの場合でも解決にならない。**

## 2-D. 報酬が発生する条件（タイミング設計の根拠）

> リンクがクリックされ → **24時間以内にカゴに入り** → **89日以内に購入**されると報酬。

- 勝負は**クリックから24時間**。ここでカゴに入らないと消える
- だからセール前日の夜〜当日朝に投稿を寄せるのが効く
- 逆に、カゴにさえ入れば購入が3か月先でも拾える

## 3. 伸びる／伸びないの分岐点

| 効く | 効かない |
|---|---|
| テーマを1本に絞る（例：共働き・小2の母の時短、狭い賃貸の湿気対策） | 何でも屋のROOM |
| 自分で使った**感想型**のコメント（上位ランクほどこの型） | 商品説明のコピペ |
| 1枚目の写真が明るい商品を選ぶ | 暗い・生活感のある写真の商品 |
| セール期（5・0のつく日、マラソン、SALE）に投稿を寄せる | 平日深夜に量だけ投げる |
| クリックは多いが売れない投稿の**コメントを書き直す** | 投稿しっぱなし |
| 他ユーザーへのいいね回り（発見されるための導線） | フォロー返し狙いだけの無差別フォロー |

**分析の起点はこの2つだけ:**
- クリックが少ない → 商品選定と1行目が悪い
- クリックは多いが売れない → 紹介文の後半（実害の描写と背中押し）が弱い

## 4. 越えてはいけない線（アカウント停止に直結）

投稿文の狙いが「放置したらどうなるか」を想像させる方向なので、ここは毎回チェックする。

- ❌ 薬機法：「治る」「効く」「改善する」「痩せる」「アレルギーが治まる」
  → 化粧品・健康食品・健康器具・ペット用品で特に厳しい
- ❌ 景表法：「No.1」「絶対」「必ず」「日本一」（根拠のない最上級・断定）
- ❌ 根拠のない「限定」「ここだけ」「今だけ」
- ❌ 自己購入による報酬取得（セルフアフィリエイト）
- ❌ 事実と違う体験談（使っていないのに「使ってます」）

### 安全な言い換え
| NG | OK |
|---|---|
| 花粉症が治る | 朝の掃除が1回で終わるようになった |
| 効果絶大 | うちでは3週間ニオイが戻っていない |
| No.1の吸水力 | レビュー◯件で★4.6（2026年◯月時点） |
| 絶対買うべき | 買い直したのはこれだけ |
| 冷え性が改善 | 足先が冷たくて眠れない夜が減った（個人の感想） |

**原則：効果を断定せず、自分の生活で起きた変化を事実として書く。**
これは規約対策であると同時に、いちばん売れる書き方でもある。
