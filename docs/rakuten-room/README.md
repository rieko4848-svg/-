# 楽天ROOM 収益化キット

商品を説明する投稿をやめて、「困り事 → 放置したらどうなるか → だから今これ」で書くための一式。

| ファイル | 中身 |
|---|---|
| [00-strategy.md](00-strategy.md) | 報酬の仕組み・商品選定の3条件・週1のリサーチ手順・規約・2026年後半カレンダー |
| [01-post-templates.md](01-post-templates.md) | 投稿文の3つの型・実害の4方向・1行目ストック30本・投稿前チェック |
| [02-post-examples.md](02-post-examples.md) | そのまま使える投稿文20本（2026年 秋〜冬） |
| [03-profile.md](03-profile.md) | プロフィール診断・テーマの絞り込み・書き直し案・再開1週目のメニュー |
| [room-lab.html](room-lab.html) | 上記をスマホで使える形にした投稿文ジェネレーター（規約チェッカー付き） |

## 使う順番

0. `03-profile.md` でプロフィールとテーマを整える（最初の1回だけ）
1. `00-strategy.md` の3条件で、今週の投稿候補を5〜8件に絞る
2. 1件ずつ「これを買わないと、来週どんな小さな損をする？」を1行で書く
3. `room-lab.html` かテンプレートで投稿文を組む
4. 投稿前チェックを通してから投稿する
5. 1週間後、クリック数と売上で判定
   - クリック少 → 商品選定と1行目
   - クリック多・売上0 → 実害の描写（2〜3行目）

## 注意

- 報酬率・セール日程・ランキングの傾向は変動します。投稿前に公式で確認してください。
- 体験として書く部分は、必ず自分の事実に差し替えてください（使っていない商品の体験談は規約違反です）。
- 薬機法・景表法に触れる表現はアカウント停止に直結します。`00-strategy.md` の言い換え表を毎回通してください。
