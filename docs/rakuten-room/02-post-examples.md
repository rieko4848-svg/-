```
これは掃除機なしで、巻いて空気を抜くだけ。
去年これに替えて、春に出したセーターがそのまま着られました。

10月のマラソン中にまとめ買いしておく枠です。
```

```
で、1月の電気代を見て後悔した。暖房を強くしていた分です。

先に足元だけ温めるほうが、部屋ごと温めるより安い。
デスクの下に置いて、スイッチ1つ。

ブラックフライデーで確保しておくやつです。

#足元ヒーター #電気代節約 #冷え対策 #在宅ワーク #冬支度 #楽天ROOM
```

### 9. 加湿器 / 加湿対策
```
喉が痛い朝、原因は風邪じゃなくて湿度かもしれません。

これが毎晩続く3か月を、何もせず過ごすかどうかの話です。
（※加湿は環境を整えるもので、病気を防ぐものではありません）

寝室に置いて、水を入れるだけ。
お手入れが面倒にならない、パーツが少ないものを選ぶのが正解でした。

#加湿器 #乾燥対策 #寝室 #冬支度 #湿度 #楽天ROOM
```

## 使い方

1. 上から自分のROOMのテーマに合うものを5本選ぶ
2. `【商品名】`と数字・体験を**自分の事実に**差し替える
3. 投稿前に `01-post-templates.md` の自己チェックリストを通す
4. 投稿は**セール前日の夜**か**5・0のつく日の朝**に寄せる
5. 1週間後、クリック数と売上を見る
   - クリック少 → 1行目を別の型に差し替えて再投稿
   - クリック多・売上0 → 実害の描写（2〜3行目）を具体化する
