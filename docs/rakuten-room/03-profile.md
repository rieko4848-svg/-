# プロフィール診断と書き直し

対象：`🌿 50代からのご自愛ライフ｜ゆらぎ世代`（2026年1月開始／8か月で成果2件／現在休止中）

---

## 診断：悪いのは商品選びより先に、ここ

### ① 名前が長すぎる（唯一、数字で裏が取れている問題）

> **Aランクユーザー30名の調査で、30人中26人（93.3%）が4文字以下の名前。**

現在の名前は20文字超。ROOMでは名前が
「いいね一覧」「フォロワー一覧」「投稿の下」に小さく出るため、
長い名前は**途中で切れて、二度と思い出されない**。

Aランクの9割以上が4文字以下という一致は、偶然ではなく構造。

### ② テーマが4本ある＝何でも屋

```
✓ 忙しい朝を助ける時短アイテム
✓ ゆらぎ世代の美容・セルフケア
✓ 気分が上がる服・小物
✓ 暮らしを整える日用品・家電
```

続いて収益を出している人の共通点は**「テーマが1本に絞られていること」**。
4本あると、検索でも記憶でも引っかからない。

### ③ 言葉が「気分ワード」で、「悩みワード」がない

| 今ある言葉 | 問題 |
|---|---|
| ご自愛 | **誰も検索しない**。自分を指す言葉ではない |
| 心地よくする | 検索されない。買う理由にならない |
| 気分が上がる | 「今すぐ買う」の締切がない |
| ゆらぎ世代 | 化粧品業界の言葉。当事者が自分の検索語として使うかは疑問 |

**全部「自分が良いと思うもの」側の言葉**で、「今、問題を解決できるもの」側の言葉がゼロ。

### ④ いちばん効いてしまっている一文

> 実際に**気になったもの**、リピート**したい**ものを中心に掲載中です。

「気になった」「〜したい」＝**まだ買っていない**という宣言になっている。

- オリジナル写真が売上5.8倍という話と、真正面から逆行している
- 読み手からは「この人も私と同じで、まだ持っていない人」に見える
- ROOMで強いのは**感想型**。その原資が最初から無いと宣言してしまっている

### ⑤ 締めが受け身

> 気になるものはコレクションからどうぞ。

どこを見ればいいのか指示がない。1本だけ名指しするほうが動く。

### ⑥ 薬機法の地雷を主軸に置いている

「ゆらぎ世代の美容・セルフケア」は、更年期・ホルモン・肌の変化に触れる領域で、
**薬機法の表現規制がいちばん厳しい**ゾーン。
ここを主軸にすると、書くたびにリスクを踏むことになる。

---

## 強み：ここだけは絶対に捨てない

> **フルタイムで働く50代**

これは資産。理由：

- 困り事が**具体的で、時間と体力という数字で書ける**（朝が足りない／夕方に切れる／老眼／冷え）
- **本人が当事者**なので、体験と写真が本物になる
- 「主婦の節約」より競合が薄い

問題は、この強みが4本のテーマに薄められていること。

---

## 絞るならここ

### 🎯 「フルタイムで働く50代の、朝と夜を短くする道具」

| なぜこの1本か | |
|---|---|
| 困り事が時間と体力 | **数字で書ける**（毎朝◯分、帰宅後◯分） |
| 薬機法 | 踏まない。効果ではなく所要時間の話になる |
| 価格帯 | 日用品・時短家電と重なり、**1,000〜5,000円の回転帯** |
| 写真 | 自分が当事者なので**オリジナル写真が撮れる** |
| 締切 | 朝は毎日来る。買う理由が常にある |

**美容・セルフケアは捨てない。** 角度を変えて吸収する。
「ゆらぎ世代の美容」→ **「時間がない人の、手抜きでいいケア」**。
これなら時短テーマの中に収まり、薬機法も踏みにくい。

服・小物は一旦外す（買う締切が作りにくい）。

## 書き直し案

### 名前（「りえ」入り・4文字以下）

名前にキーワードを詰め込む必要はない。**検索に引っかかるのはプロフィール文のほう**なので、
名前は「覚えやすさ・呼びやすさ」だけで選んでいい。

#### A. テーマが先に来る型（何の人かが一瞬で伝わる）

| 案 | 字数 | 意図 |
|---|---|---|
| **あさりえ** ◎ | 4 | 朝＝主戦場が名前に入る。全部ひらがなで読みやすく、人名としても成立。呼びやすい |
| **5分りえ** | 4 | 数字は一覧の中で視覚的に目立つ。「5分」がテーマそのもの |
| **時短りえ** | 4 | 検索ワード直結。ただしやや業務的で、人の気配が薄い |
| **ラクりえ** | 4 | 今の「毎日を少しラクに」を残せる |

#### B. 「りえ」が先に来る型（人として覚えてもらう）

| 案 | 字数 | 意図 |
|---|---|---|
| **りえ5分** | 4 | 人名が先。一覧で切れても「りえ」が残る |
| **りえ子** | 3 | いちばん人名らしい。テーマは伝わらないが親しみは最大 |
| **りえ** | 2 | 最短・最強に覚えやすい。ただし同名に埋もれる可能性 |

#### C. 今の名前を引き継ぐ型

| 案 | 字数 | 意図 |
|---|---|---|
| **ゆらりえ** | 4 | 「ゆらぎ世代」の名残を残す。既存フォロワーが違和感を持ちにくい |

#### 推し：**あさりえ**

- 4文字・全部ひらがな＝一覧で切れず、読み間違いもない
- 「朝」がテーマそのもの。プロフィール2行目の「朝が、とにかく足りません」と直結する
- 人名として自然なので、コメントで「あさりえさん」と呼んでもらえる
  （呼ばれる名前は記憶に残る。ここが4文字ルールの本質）

**注意：** 名前を変えてもフォロワーは消えない。移行コストはゼロ。

### 自己紹介文

```
フルタイムで働く50代です。
朝が、とにかく足りません。

・5分早く家を出られたもの
・帰宅後の「もう無理」が減ったもの
・買い直さずに済んだもの

この3つだけ載せています。
値段ではなく「何分減ったか」で選びました。

美容も、時間をかけない方法だけ。

※実際に自分で使っているものだけを載せています。
　迷って買わなかったものは載せません。

まずは「朝」のコレクションからどうぞ。
```

**変えた点**

| 変更 | 理由 |
|---|---|
| 「ご自愛」「心地よく」を全削除 | 検索されない |
| 「朝が足りません」を2行目に | 悩みワードを最上部に置く |
| 3本の箇条書きを**すべて過去形**に | 「気になった」→「減った」。体験の宣言に変わる |
| 「何分減ったか」 | 選定基準を明示＝信用 |
| 「迷って買わなかったものは載せません」 | 掲載しないものを宣言すると、載っているものの価値が上がる |
| 締めを「朝のコレクション」に名指し | 動線が1本になる |

※「実際に自分で使っているものだけ」は**事実であるときだけ**書くこと。
　使っていないものも載せるなら、この行は入れない（規約違反になる）。

## 再開1週目のメニュー

8か月止めていても、失ったものはほぼない（ランク条件は3か月に1回、通算投稿枠20,000は無傷）。

| 日 | やること | 時間 |
|---|---|---|
| 1日目 | 名前と自己紹介を書き換える | 15分 |
| 2日目 | 家の中を見て、**この1年で買ってよかったもの**を5つ書き出す | 15分 |
| 3日目 | そのうち1つを明るい場所で撮って、**オリジナル写真で1本目**を投稿 | 20分 |
| 4〜7日目 | 判定シートで1日1商品だけ選び、投稿1件。いいね返しだけやる | 各15分 |

2日目がいちばん大事。**ここで出た5つが、この先いちばん売れる弾になる。**

## 8か月で2件について

止めている間も売れたということは、**導線自体は死んでいない**（検索やコレクション経由で人は来ている）。
つまり問題は「見られていない」ではなく、**「見られたが、買う理由が伝わらなかった」**側にある可能性が高い。

そこは商品選びではなく、プロフィールと投稿文で直せる場所。
