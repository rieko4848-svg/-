## 診断

### 強い（そのまま活かす）

- **自前の写真が9枚ある** — オリジナル写真の弾がすでに手元にある
- **テーマど真ん中** — 「あさりえ／朝」に完全一致
- **体験が本物** — 前夜に仕込む、バナナ、キウイ、オリゴ糖、ゆで卵。実際に食べている人の文章
- 価格 ¥2,080 = 回転帯。食品なので料率4%前後（報酬 約83円）

### 直す

| 問題 | 中身 |
|---|---|
| **#オリジナル写真がない** | 9枚も自前写真があるのに、審査の列に並んでいない |
| **1行目に困り事がない** | 「毎朝の楽しみ、オーバーナイトオーツ」＝気分ワード。見えるのは最初の2〜3行なのに、そこに刺さる要素がない |
| **放置したらどうなるかがゼロ** | 全体が日記になっていて、買う理由が発生しない |
| **「お腹の調子も全然違う」** | 食品で体調の変化を断定するのは薬機法・健康増進法でグレー。**削除する** |
| 写真が暗め | 手持ち・袋にシワ・背景が暗い。承認基準「明るく・はっきり」に対して不安。9枚から明るいものを選ぶか撮り直す |

### 構成の対応

| 行 | 役割 |
|---|---|
| 1行目（23字） | 困り事の名指し。商品名を入れない |
| 2〜4行目 | **放置の実害**。⏳時間で数字化（週3〜4回／朝10分／14時間） |
| 5〜6行目 | 転換＋**動作1つ**（入れて、寝る） |
| 7〜8行目 | 使用イメージ＋自分の事実（感想型） |
| 9行目 | **今買う理由**。ポイント3倍は9/14まで＝実在の締切 |
| タグ | 半角#。**#オリジナル写真を先頭に** |

### 薬機法チェック

- 「お腹の調子も全然違う」→ **削除**（食品で体調の改善を示唆しない）
- 残したのは「ちゃんと食べられる」＝事実の記述のみ
- 昼のドカ食いの話は**自分の生活描写**であり、商品の効果を謳っていない

## 手順（順番が重要）

> **⚠️ 先に削除しないこと。** 写真が端末に残っていないと復元できない。

1. **カメラロールに9枚の写真が残っているか確認する**
   - 残っていない → 商品がまだ家にあるなら撮り直す。無ければ古い投稿は触らない
2. 同じ商品をもう一度「コレ！」する
3. 写真を添付。**いちばん明るく、袋が大きく写っている1枚を先頭に**
4. 上の文を貼る
5. **`#オリジナル写真` が青字になっているか目視で確認**（半角#）
6. 投稿
7. **新しい投稿が問題なく表示されたのを確認してから**、5月14日の古い投稿を削除
8. 3日待って、`自分のアイコン → ROOMランク` の
   「#オリジナル写真の投稿またはファッションコーディネート投稿をしよう」に
   チェックが入るか確認

## 写真の注意（承認基準）

- 商品**それだけ**を写す（他の商品が写り込むとNG）
- 明るい場所で。日中の窓際が確実
- パッケージが**リンク先の商品と一致**しているか（リニューアル前後に注意）
- ピンぼけ・引きすぎを避け、**大きく**

袋のシワは問題にならない。**暗さと写り込みのほうが危ない。**
