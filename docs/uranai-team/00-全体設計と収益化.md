# 占い垢運用チーム 全体設計

## この文書の位置づけ

占い系SNSアカウントを「チーム運営」として立ち上げる場合の設計図。
`設計 / 投稿 / 鑑定 / チェック / 数字 / お客さん / 段取り` の7役割に分割し、
それぞれの担当ファイルで具体的な業務を定義する。1人で始める場合も、
どの役割を今どの帽子で被っているかを意識するために使う。

## アカウントコンセプト(たたき台)

- **母艦プラットフォーム**: X(Twitter)。画像・短文との相性がよく、占い垢の主戦場。
- **導線**: 無料の日常投稿(タロット1日1枚、星座別ワンポイントなど)で
  フォロワーを増やし、DM・LINE公式アカウントでの個別鑑定(有料)に誘導する。
- **ジャンルと差別化軸は1つに絞る**: タロット/西洋占星術/四柱推命/手相などの手法と、
  毒舌系・優しい系・恋愛特化などのキャラクターは、後から広げるより最初に絞ったほうが伸びやすい。
- **投稿頻度**: 最低でも1日1投稿を継続できる体制が前提条件。続けられない設計は
  最初から見直す。

## 収益化: 現実的なライン

| 収益源 | 現実度 | 目安 |
|---|---|---|
| 個別鑑定(DM/LINE通話・チャット) | ◎ 主軸 | フォロワー数千〜1万で予約が入り始める。1件 ¥1,000〜¥5,000/15〜30分が初期相場 |
| note等の有料記事(月間運勢・個別解説) | ○ | フォロワー数千から少額の副収入になる |
| オンラインサロン・月額コミュニティ | △ | 固定ファンがついてから。初期には非現実的 |
| 企業タイアップ・PR投稿 | △ | フォロワー1万〜が目安。初期は期待しない |
| 物販(オラクルカード・お守り等) | △ | 在庫リスクあり。優先度は低い |

**前提として、最初の3〜6ヶ月は無収益を想定し、フォロワー基盤と鑑定の実績(お客様の声・ポートフォリオ)作りに専念する。** 収益を急いで「当たる」「必ず」といった誇大表現に頼ると、後述の法令リスクが跳ね上がるので避ける。

## 法令・倫理面の必須事項

- **特定商取引法に基づく表記**: 有償の個別鑑定を提供する時点で表記義務が発生する(事業者名、連絡先、料金、返金条件など)。
- **景品表示法・優良誤認表示の回避**: 「絶対当たる」「必ず幸せになれる」など断定的な効果保証はNG。エンタメ・カウンセリング目的である旨を明記する。
- **医療・法律行為との線引き**: 病気の診断・治療、法律相談に類する助言はしない。必要な場合は専門家への相談を促す。
- **未成年・過度な高額請求への配慮**: 未成年からの高額鑑定依頼は原則断る。依存を助長する営業(不安を煽って追加課金させる等)はしない。
- **個人情報・鑑定内容の秘匿**: 相談内容のスクリーンショットや引用投稿は本人の同意なしに行わない。

## 新規アカウント開設の判断基準

以下がすべて「Yes」なら着手して良い。1つでも「No」なら、既存アカウントの一角で
小さく試す(週数回の投稿でテストする)ところから始める。

1. ジャンルとキャラクターを1つに絞れているか
2. 毎日1〜2投稿を最低3ヶ月続けられる体制(人・時間)があるか
3. 個別鑑定を実施できるスキル・時間が確保できているか(自分 or チームメンバー)
4. 有償鑑定を始める際の特定商取引法表記・料金体系を用意できるか
