# 目次: 睡眠(寝つき・眠りの質)

## 1. 伝えたい要素の棚卸し(`evidence-db.md` より)

1. 運動(特に高強度な運動)を取り入れると睡眠の質(PSQI)が改善する(HIIT研究)
2. 運動だけでなく、食事・睡眠衛生など複数の生活習慣要素を組み合わせた介入で睡眠の質が改善する(メタ分析・効果量あり)
3. ただしその効果は、今のところ短期(3か月未満)でしか確認されていない
4. 職場でも、睡眠衛生教育+行動的アプローチ(リラクゼーション・刺激制御法・睡眠制限法)で不眠傾向がある人の睡眠が改善した実例がある
5. スマホアプリのような手軽なデジタル介入でも、軽度の睡眠の悩みには効果が示されている
6. 昼寝は状況によって逆効果にも良い効果にもなる。自分の「睡眠負債」の大きさによって、適切な昼寝の長さが変わる(相関研究であり因果は断定できない)
7. 睡眠の質改善に「唯一の正解」はなく、複数のアプローチから自分に合うものを選ぶという方針が現実的

## 2. スタート地点とゴール地点

- **スタート地点**: 布団に入ってもなかなか寝付けない、眠りが浅くて日中だるさを感じている。ネットで色々な「快眠法」を試したが体験談ベースの情報ばかりで何を信じていいか分からず疲れている。
- **ゴール地点**: 論文に裏付けられた具体的な選択肢(運動・生活習慣改善・行動的アプローチ・アプリ・昼寝の使い方)を知り、研究の限界も理解した上で、今日から無理なく一つ試せる状態になっている。
