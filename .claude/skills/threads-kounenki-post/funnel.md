# 集客導線(ファネル)の型 — 参考メモ

ユーザーが「この型、覚えておいて」と保存を頼んだ、伸びているアカウントの集客導線。
今すぐ作るものではなく、フォロワーと「配れる物」がそろってから使う。

## 参考にした実例(2026/10 時点、むぎ @mugi_8919)

| 段階 | 中身 |
|---|---|
| ① スレッズのプロフィール | 名前欄「むぎ@楽天アフィリで夢を叶えるママ」。1行目に実績(＼楽天アフィリで月119,613円／)、手軽さ(写真動画なし・文字だけ／1日10分から)、「↓無料プレゼントはリンクから受け取り🎁↓」＋リンク |
| ② LP(受け取りページ) | 大きな見出し「たった2日で66,102円の報酬が出た方法を大公開！」「成果に繋がった投稿の型も暴露」、安心材料(無料・1日10分・スマホ1台)、「プレゼントを受け取る」ボタン |
| ③ 登録フォーム | メールアドレスだけ入力。Gmail・Yahoo推奨の注意書き |
| ④ サンクスページ | 「ご登録ありがとうございます。プレゼントをお送りします」「メルマガでお会いできるのを楽しみに」 |
| ⑤ その先(推測) | メルマガ(ステップ配信)→ 講座・コンサルなど有料商品の案内 |

無料コンサル(60万円の講座の入り口)で聞いた「Instagramのハイライト → 公式LINEに誘導 → ステップ配信」も同じ形。
受け皿がメールかLINEかの違いだけ。

## 型の骨組み

1. **スレッズの投稿**で役に立つ・共感される発信をして、プロフィールを見に来てもらう
2. **プロフィール**で「何の人か」「フォローすると何が得られるか」＋**無料プレゼント**への案内
3. **LP**で、プレゼントの中身と「もらうとどうなるか」を見せる
4. **メールアドレス(またはLINE)を登録**してもらう
5. **ステップ配信**で信頼を深め、おすすめ商品や自分の商品を案内する

## りえさん(@rie_kounenki_now)に当てはめるときの注意

- **プレゼントの候補**: 更年期のゆらぎセルフチェック、働く50代のほっと時間リスト、
  耳つぼ×栄養で私が気をつけていることメモ など。本人の体験と知識で作れるもの
- **出口(何を案内するか)を先に決める**: むぎさんの出口は「稼ぎ方を教える講座」。
  りえさんは自分の商品がまだないので、最初は「楽天のおすすめを届けるメルマガ／LINE」が出口。
  YouTube「50代の心と体を整えるまったりカフェ」や、将来の自分の商品につなげる道もある
- **実績を盛らない**: 「〇日で〇万円」のような数字は、実際に出た実績だけ。
  健康・体重の分野では「〇kg痩せた方法」のような見出しは使わない(効果の断定になる)
- **メルマガ・LINEの法律**: 送るには相手の同意、送信者の名前と連絡先、配信停止の方法の表示が必要(特定電子メール法)。
  メールアドレスを集めるならプライバシーポリシーも用意する
- **始めどき**: フォロワーが数百人になり、コメントが継続して来るようになってから。
  公式LINEは無料プランだと毎月送れる数に上限があるので、始めるときに確認する
- 「稼ぎ方」を売る人は、アフィリエイトの報酬より講座の売上が中心のことが多い。
  見出しの数字はそのまま信じず、型だけを参考にする

## 実例2: 由美 @yumi202376(楽天トラベル)

ユーザーいわく、無料コンサルで案内された60万円講座の受講生らしい。むぎさんと同じ型。

| 段階 | 中身 |
|---|---|
| プロフィール | 名前欄「由美｜楽天アフィリ×AIで月10万円」。【楽天アフィリ×AIでおうちで月10万円のやり方公開中】／ワンパターンネタ＆文章で月10万円／テンプレに当てはめるだけ、写真・体験談不要／↓無料レポートはリンク／2児のママ |
| 固定投稿 | 「え…楽天トラベル、想像以上に伸びやすくて衝撃…もっと早くやっておけばよかったって本気で後悔してる😂😂」＋楽天アフィリエイトの管理画面のスクショ(成果報酬の数字を赤枠) → リプ欄「楽天トラベルなら写真もいらないし、買わなくていいし、体験談もなしで16日で66,608円になりました！私が伸ばせたネタと投稿文はここから見れます👇」＋LPのリンク |
| LP | 「Threads×楽天トラベル 7日で2万円→27日で18万円超！」「『何を投稿する？』がわかる♪ 実際に伸びたバズネタ＆投稿文をプレゼント！」→ メールアドレス → 「メルマガでプレゼントを受け取る」。利用規約・プライバシーポリシーへの同意つき |

| 登録後のページ(メルマガ登録完了) | 大きく「ありがとうございました！」＋本人のキャラのイラスト(猫・パンダの仲間つき)。「メルマガのご登録をありがとうございました！」→ 送信元アドレス(info@〜)を明記 →「迷惑メールに入ったら『迷惑メールではない』を押して」→ ★メールアドレス登録のお願い★「今後もメルマガで収益アップを目指す情報や、読者さん限定のプレゼントをお渡しすることも」→ 受信設定のやり方のページへのリンク → 登録してほしいアドレスを再掲 →「しばらくたってもメールが届かない場合は、アドレスを確かめてもう一度登録を」→ 署名「由美」 |

ポイント:
- 固定投稿が「驚き・後悔」の感情＋**管理画面のスクショ**という証拠で手を止めさせ、リプ欄でLPへ
- 「写真いらない・買わなくていい・体験談なし」という**手軽さ**を前に出している
- 登録フォームに**利用規約とプライバシーポリシー**を置いている(りえさんが作るときも必要)
- 登録完了ページで**メールが届くための手当て**を全部している: 送信元アドレスの明記、迷惑メール対策、
  受信設定のやり方、届かないときの対処。せっかく登録してもらってもメールが届かなければ意味がないため
- 「今後も役立つ情報や読者さん限定のプレゼントを送る」と、**メルマガを読み続ける理由**をここで伝えている
- キャラのイラストと「ありがとうございました！」で、**登録した人を歓迎する**温かい雰囲気にしている
- りえさんが作るときの登録完了ページの中身(案): お礼／送信元アドレス／迷惑メール・受信設定の案内／
  届かないときの対処／このメルマガで届けるもの(更年期のゆるケア、ほっと時間、おすすめの宿や愛用品など)／署名「りえ」。
  アイコンのうちわを持ったキャラを使うと、スレッズからの流れがそろう

## 楽天トラベルについて

- 宿を紹介する投稿で、リンクから予約されると成果になる。商品を買って試さなくても紹介しやすく、
  リンクのカードに宿の写真が出るので写真もいらない
- 成果は**予約しただけでは確定せず、宿泊が終わってから**確定する扱いになるので、
  報酬が見えるまで時間がかかる。キャンセルされると成果にならない
- 料率や条件は変わることがあるので、使い始めるときに楽天アフィリエイトの管理画面で確認する
- 更年期アカウントとの相性: 「がんばった自分へのごほうび」「ひとりでほっとできる温泉宿」
  「母と娘の旅」など、**ほっと時間・セルフケア**の文脈で自然に紹介できる
  (投稿の書き方は SKILL.md の ⑧ 楽天トラベル型)

## 実例2の続き: メルマガ1通目(登録直後に届くメール)

件名「【プレゼント】今日からコレで稼いでください！」。送信元 info@〜、署名「由美」。
※本文は著作権で保護され無断転載お断りと書かれているので、ここには**構成と工夫だけ**を残す。

### 構成(上から順に)
1. **あいさつ**「こんにちは！由美です。」＋Gmailで文字が崩れたときの対処
2. **お礼**と、このメルマガで話すこと(楽天トラベル×Threadsで27日に約18万円まで伸ばした話)
3. **「明日からもメルマガ限定のプレゼントを渡すので、数日だけでも読んで」**＝次のメールも開いてもらう約束
4. **自己紹介と始めたきっかけ**: ブログ歴10年(楽天で月16万円)／ブログは時間がかかる／
   9月に体調が悪く「もっと短い時間でできることを」と思ってThreadsを始めた
5. **失敗から入る**: 最初は閲覧数「4」だったこともある(笑)
6. **転機と数字**: ネタを変えたら閲覧数が1.5万→4.5万→最高11万超、報酬も11日・16日・27日と段階的に伸びた
7. **手軽さ**: 調べて・行って・画像を作って・長文を書く、ではない。2〜3行の投稿でOK。
   煮物を煮込んでいるとき、子どもがテレビに夢中のとき、ソファで5分
8. **これから話すこと**:「何を狙って、どこからネタを探して、どんな投稿をしているか」を暴露する、ブログの話も今後
9. **約束のプレゼントのリンク**(1回目)
10. **今日の大事なこと(お得な一言)**:「迷ったらまず楽天トラベル」。理由＝報酬が一気に伸びた／
    1つネタを見つけると次も見つかる／過去の投稿文を使い回せる／短くてシンプル
11. **プレゼントの中身の予告**: どんなネタ・どんな文章・なぜ伸びたか。「こんな人に」と悩みを3つ並べる
12. **プレゼントのリンク**(2回目。＼／で囲った見出しつき)
13. **人柄**: 小学生2人のママ、子どもが学校の間だけ家で仕事、ゴロゴロしながらスマホで投稿文を考える
14. **「一緒に楽しんでいけたら」**で仲間に誘う
15. **質問・感想の受付フォーム**へのリンク
16. **迷惑メール対策のお願い**(受信設定のやり方へのリンク。特典パスワードの再発行は有料、と書いて設定を促す)
17. **発行者情報**: 発行者名、ブログ・X・Threadsのリンク、特定電子メール法の表記ページ、
    メールアドレス変更、配信解除のリンク、「アフィリエイト広告を利用することがある」、無断転載禁止

### 工夫していること
- **プレゼントのリンクを2回**置いている(途中と、中身を予告したあと)
- **失敗(閲覧数4)→転機→数字**の順で、読む人が「私にもできそう」と思える流れ
- **体調が悪かった時期に始めた**、**スキマ時間の具体的な場面**など、生活感のある話で親近感を出す
- 1通目で**「迷ったらまず楽天トラベル」というすぐ使える答え**を1つだけ渡して、満足感を作る
- 「明日からも限定プレゼント」で**2通目以降を開く理由**を先に作っている
- 最後に**質問フォーム**で、読者と1対1でつながる入り口を作っている
- 末尾に**法律で必要な表記(発行者・連絡先・配信解除)**と、アフィリエイト広告を使うことの表示をまとめて置いている

### りえさんが1通目を書くときの骨組み(案)
1. あいさつ・お礼 →「このメルマガで届けること」(働きながら更年期のゆるケア、ほっと時間、愛用品・宿)
2. 「明日からも、読者さん限定の〇〇をお届けします」
3. 自己紹介と始めたきっかけ(57歳・フルタイム・更年期まっただ中、体重が増えてきた、耳つぼの資格はあるけど私も奮闘中)
4. しんどかったこと → 少しラクになったこと(**本人の体験だけ**。効果は言い切らない)
5. 約束のプレゼントのリンク
6. 今日のひとこと(すぐ試せる小さなこと1つ)
7. 人柄(仕事の合間・夜の時間など、本人の生活の場面)
8. 「一緒にゆるく」と仲間に誘う → 質問・感想フォーム
9. 迷惑メール対策のお願い → 発行者情報・特定電子メール法の表記・配信解除・アフィリエイト広告を含むことの表示
- 由美さんの「〇日で〇円」にあたる数字は、**実際に出た実績ができるまで書かない**

## 実例2の続き: プレゼント(メルマガ限定ページ)の中身

URL は yumimama-afiri.com/mail/threads-travel-present(作業環境からは開けないので、ユーザーのスクショで確認)。
文章はそのまま写さず、**分かったこと**だけを残す。スクショは数回に分けて受け取り中。

### ここまでで分かったこと(1回目のスクショ5枚)
- ページの一番上に「※このサイトではアフィリエイトリンクを掲載しています」と表示
- LPと同じバナー画像 →「こんにちは！由美です」→ 9月からThreadsで楽天トラベルのアフィリエイトをしている
- **仕組みの図解**: 私が投稿する → 見た人がリンクをクリック → 楽天トラベルでホテル・飛行機＋宿・レンタカーなどを予約 →
  条件に応じて報酬が発生。「ホテル」だけでなく「飛行機＋宿」「レンタカー」も対象
- 見出し「**一度伸びた文章が、次にも活かせる**」:
  伸びたネタ(例: 沖縄のホテルが全日程で半額になるプラン)は、**そのお得なプランがまだ使える間なら、
  数日後に言い方や切り口を変えてもう一度投稿できる**。「まだあるんだけど！」「これまだやってる！」のように、
  **追加情報を伝える形**にすれば同じネタを何度も使える → 毎日まったく新しい文章を書かなくてよい
- 投稿例は**キャラのふきだし**で見せている。どれも1〜2行、叫ぶような話し言葉(「ちょ、〇〇行く人ーー！！」「ギャーーー！！！」)
- 見出し「**フォロワー数が少なくても実践できる**」: フォロワー15人くらいの頃から閲覧数は伸びていた、
  という話＋インサイトのスクショ(7日間で閲覧14万)

### 由美さんの方法の芯(ここまでの理解)
- ネタは**楽天トラベルのセール・お得なプラン情報**(半額など)。「お得情報を短く叫ぶ」投稿
- 同じセールが続く間は、**切り口を変えて何度も投稿**する

### りえさんが使うときの注意
- SKILL.md の ⑧ は「値段・セール・クーポンは書かない」にしてある(変わるため)。
  セール情報を使うなら、**投稿する直前に楽天トラベルのページで本当にやっているか確認する**、
  **「〇月〇日時点」と書く**、終わったら**投稿を消すか「終了しました」と追記する**、が最低限必要
  (古い情報のまま残すと、実際よりお得に見せる表示になるおそれがある)
- 「ギャーー！」のような叫び系は由美さんのキャラ。りえさんは**更年期・ほっと時間のテーマに合う言い方**に変える
  (例:「がんばった自分へのごほうびに、ちょうどいいプランを見つけてしまった…」)
- 文章・言い回しはまねず、型(短い・お得情報・同じネタを切り口を変えて再投稿)だけを使う

### プレゼントページの全体(Wordで受け取った全文から。要点だけ)
目次: 最初はたった4回表示 → 伸ばせたネタ → 実際の投稿文 → AIで作った文章 → なぜ楽天トラベルか
(ネタがいっぱい／芋づる式／難しい文章は不要／伸びた文章を次に活かせる／フォロワーが少なくてもOK／1件の報酬が大きい)
→ 旅行に詳しくなくても大丈夫？ → これからもシェア → 質問・感想

- **やり方の芯**: 楽天トラベルで「ホテル半額」「1万円引きクーポン」などの**お得情報**を見つけて、驚きの気持ちを2〜3行で投稿するだけ。
  ホテルの説明・感想・長文は書かない。「えっ！何それ！？」と思ってもらえる**ネタ探しがいちばん大事**
- **狙うネタ**: ホテル半額、50%OFF、〇千円OFFクーポン、子ども無料、期間限定プラン、地域限定キャンペーン。
  楽天トラベルの**トップページ**や**クーポンのページ**に大きく出ていることが多い。**割引額がパッと見て大きいもの**が伸びやすい。
  いちばん伸びたのは楽天スーパーセール限定の「全日程半額プラン」(最高6.4万表示)
- **芋づる式**: 1つ見つけたら**地域を変える**(沖縄→北海道→東京→大阪)だけで次のネタになる
- **再投稿**: 同じプランがまだ使えるうちは、言い方を変えて「まだある！」と追加情報として何度も投稿
- **AIの使い方**: 自分の文章の「型」を読み込ませたAI(ChatGPT)に、楽天トラベルの画面のスクショやURLを貼ると投稿文の例が出る。
  そのまま投稿せず、手直ししてから出す
- **続け方**: 最初の投稿は4表示、その後も14〜39表示。「3日やってダメならやめよう」と決め、
  その日に5投稿ほどしたら300〜500表示が出始め、あるネタで4,734表示 → 1万表示超えも。1日に数回投稿
- **報酬の出方**: 2日目121円、3日目658円、5日目1,934円 → 7日間で約2万円 → 27日間の累計188,408円
  (**ブログの報酬も含む**。うち楽天トラベルは46%の87,047円)。宿泊は1件で数千円になることもある
- **フォロワー**: 15人くらいの頃から閲覧数は伸びていた
- **ページの出口**: 最後に「始め方」と「楽天トラベル×Threadsで伸ばせた教科書(PR)」へのリンク
  ＝**有料の教材をアフィリエイト(PR)で紹介**して、そこでも収益を得る形。末尾に無断複写・転載禁止の表記

### 読み取っておきたいこと
- 見出しの「27日で18万円超」は**ブログの報酬込み**。Threadsの楽天トラベル分だけだと約8.7万円
- 「1日に数回」「1日5投稿」くらいの量を出している。ネタはセール情報なので**数を出しやすい**
- りえさんが取り入れるなら: ⑧ 楽天トラベル型に「**セール・クーポン情報の短い投稿**」を加える。
  そのときは、投稿直前に本当にやっているか確認／「〇月〇日時点」を書く／終わったら削除か「終了しました」と追記、を守る
