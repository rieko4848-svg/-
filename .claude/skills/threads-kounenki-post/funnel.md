# 集客導線(ファネル)の型 — 参考メモ

ユーザーが「この型、覚えておいて」と保存を頼んだ、伸びているアカウントの集客導線。
今すぐ作るものではなく、フォロワーと「配れる物」がそろってから使う。

## 参考にした実例(2026/10 時点、むぎ @mugi_8919)

| 段階 | 中身 |
|---|---|
| ① スレッズのプロフィール | 名前欄「むぎ@楽天アフィリで夢を叶えるママ」。1行目に実績(＼楽天アフィリで月119,613円／)、手軽さ(写真動画なし・文字だけ／1日10分から)、「↓無料プレゼントはリンクから受け取り🎁↓」＋リンク |
| ② LP(受け取りページ) | 大きな見出し「たった2日で66,102円の報酬が出た方法を大公開！」「成果に繋がった投稿の型も暴露」、安心材料(無料・1日10分・スマホ1台)、「プレゼントを受け取る」ボタン |
| ③ 登録フォーム | メールアドレスだけ入力。Gmail・Yahoo推奨の注意書き |
| ④ サンクスページ | 「ご登録ありがとうございます。プレゼントをお送りします」「メルマガでお会いできるのを楽しみに」 |
| ⑤ その先(推測) | メルマガ(ステップ配信)→ 講座・コンサルなど有料商品の案内 |

無料コンサル(60万円の講座の入り口)で聞いた「Instagramのハイライト → 公式LINEに誘導 → ステップ配信」も同じ形。
受け皿がメールかLINEかの違いだけ。

## 型の骨組み

1. **スレッズの投稿**で役に立つ・共感される発信をして、プロフィールを見に来てもらう
2. **プロフィール**で「何の人か」「フォローすると何が得られるか」＋**無料プレゼント**への案内
3. **LP**で、プレゼントの中身と「もらうとどうなるか」を見せる
4. **メールアドレス(またはLINE)を登録**してもらう
5. **ステップ配信**で信頼を深め、おすすめ商品や自分の商品を案内する

## りえさん(@rie_kounenki_now)に当てはめるときの注意

- **プレゼントの候補**: 更年期のゆらぎセルフチェック、働く50代のほっと時間リスト、
  耳つぼ×栄養で私が気をつけていることメモ など。本人の体験と知識で作れるもの
- **出口(何を案内するか)を先に決める**: むぎさんの出口は「稼ぎ方を教える講座」。
  りえさんは自分の商品がまだないので、最初は「楽天のおすすめを届けるメルマガ／LINE」が出口。
  YouTube「50代の心と体を整えるまったりカフェ」や、将来の自分の商品につなげる道もある
- **実績を盛らない**: 「〇日で〇万円」のような数字は、実際に出た実績だけ。
  健康・体重の分野では「〇kg痩せた方法」のような見出しは使わない(効果の断定になる)
- **メルマガ・LINEの法律**: 送るには相手の同意、送信者の名前と連絡先、配信停止の方法の表示が必要(特定電子メール法)。
  メールアドレスを集めるならプライバシーポリシーも用意する
- **始めどき**: フォロワーが数百人になり、コメントが継続して来るようになってから。
  公式LINEは無料プランだと毎月送れる数に上限があるので、始めるときに確認する
- 「稼ぎ方」を売る人は、アフィリエイトの報酬より講座の売上が中心のことが多い。
  見出しの数字はそのまま信じず、型だけを参考にする

## 実例2: 由美 @yumi202376(楽天トラベル)

ユーザーいわく、無料コンサルで案内された60万円講座の受講生らしい。むぎさんと同じ型。

| 段階 | 中身 |
|---|---|
| プロフィール | 名前欄「由美｜楽天アフィリ×AIで月10万円」。【楽天アフィリ×AIでおうちで月10万円のやり方公開中】／ワンパターンネタ＆文章で月10万円／テンプレに当てはめるだけ、写真・体験談不要／↓無料レポートはリンク／2児のママ |
| 固定投稿 | 「え…楽天トラベル、想像以上に伸びやすくて衝撃…もっと早くやっておけばよかったって本気で後悔してる😂😂」＋楽天アフィリエイトの管理画面のスクショ(成果報酬の数字を赤枠) → リプ欄「楽天トラベルなら写真もいらないし、買わなくていいし、体験談もなしで16日で66,608円になりました！私が伸ばせたネタと投稿文はここから見れます👇」＋LPのリンク |
| LP | 「Threads×楽天トラベル 7日で2万円→27日で18万円超！」「『何を投稿する？』がわかる♪ 実際に伸びたバズネタ＆投稿文をプレゼント！」→ メールアドレス → 「メルマガでプレゼントを受け取る」。利用規約・プライバシーポリシーへの同意つき |

ポイント:
- 固定投稿が「驚き・後悔」の感情＋**管理画面のスクショ**という証拠で手を止めさせ、リプ欄でLPへ
- 「写真いらない・買わなくていい・体験談なし」という**手軽さ**を前に出している
- 登録フォームに**利用規約とプライバシーポリシー**を置いている(りえさんが作るときも必要)

## 楽天トラベルについて

- 宿を紹介する投稿で、リンクから予約されると成果になる。商品を買って試さなくても紹介しやすく、
  リンクのカードに宿の写真が出るので写真もいらない
- 成果は**予約しただけでは確定せず、宿泊が終わってから**確定する扱いになるので、
  報酬が見えるまで時間がかかる。キャンセルされると成果にならない
- 料率や条件は変わることがあるので、使い始めるときに楽天アフィリエイトの管理画面で確認する
- 更年期アカウントとの相性: 「がんばった自分へのごほうび」「ひとりでほっとできる温泉宿」
  「母と娘の旅」など、**ほっと時間・セルフケア**の文脈で自然に紹介できる
  (投稿の書き方は SKILL.md の ⑧ 楽天トラベル型)
