# CLAUDE.md ペルソナファイルの作り方(Step 3 詳細)

このファイルの目的は、「誰が・何を・どう書くか」を一度だけしっかり決めて保存し、以後は「〇〇について記事書いて」の一言で毎回同じクオリティ・同じ声で書けるようにすること。プロジェクトのルート(`evidence-db.md` や `outline.md` と同じ階層)に `CLAUDE.md` として置くと、そのディレクトリで作業する際に自動的に読み込まれる。

## 3つの要素

### ① 誰が書くか(WHO)
- 一人称(僕/私/俺 など)
- 口調・文体(丁寧語か、フランクか、断定調か疑問調か)
- 想定読者(誰の、どんな悩みに向けて書くか)
- 使わない言葉・避ける表現(専門用語の直接使用、断定しすぎる言い回し、読者を追い詰めるような言葉 など)

ユーザーから直接聞き出すのが難しい場合は、既存のSNS投稿やnote記事があれば分析して口調を抽出する。

### ② 何を書くか(WHAT)
- 主張の一次ソースは必ず `evidence-db.md`。データベースに載っていない主張を新しく作らない。
- データベースにない情報が必要になったら、Step 2 に戻って追加してから書く。

### ③ どう書くか(HOW)
- 同じジャンルで伸びている投稿・note記事の構成パターンを分析し、要素として書き出す(フックの作り方、見出しの付け方、段落の長さ、まとめ方など)。
- ユーザーに参考にしたい投稿を教えてもらうか、Web検索で同ジャンルの人気記事を探して分析する。

## 追加のキャラクター設定(推奨・ジャンルに応じて調整)

助言・健康系コンテンツでは特に以下が有効(実例は子育て系「脳育」アカウントのもの。ジャンルに合わせて言い換える):

- 読者(親、当事者など)を絶対に責めない
- 不安を煽るだけで終わらせず、必ず具体的な解決策で締める
- 専門用語・学術用語は噛み砕いて平易な言葉に言い換える

これらはハードコードされたルールというより「なぜそうするのか」を理解した上で、そのジャンルに合わせて調整すること。例えば専門性の高い読者向けなら噛み砕きすぎない方が良い場合もある。

`assets/persona-template.md` を出発点にして `CLAUDE.md` を作成する。
