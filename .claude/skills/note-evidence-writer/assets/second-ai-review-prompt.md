あなたに、健康・育児などのテーマで書かれたnote記事の下書きを査読してほしいです。この記事は、学術論文を根拠に書かれていますが、AI(Claude)が下書きを作成しているため、存在しない論文や、事実と異なる数字を書いてしまっている(ハルシネーション)可能性があります。あなたにはその誤りを見つける役割をお願いします。

添付するのは2つのファイルです。
- `evidence-db.md`:執筆時に使った論文のリスト(タイトル・発表年・掲載誌・DOI・分かったこと・研究の限界)
- 原稿(章ごと、または `full-draft.md`):実際にnoteに載せる本文

**確認してほしいことは、次の3つだけです。他の観点(文章の巧拙など)は不要です。**

1. **出てくる研究は実在するか**:原稿やデータベースに書かれているDOIを、実際にWeb検索やGoogle Scholar等で調べて、その論文が本当に存在するか確認してください。DOIが解決できない、または内容が全く一致しない場合は、具体的にどの記述か指摘してください。
2. **数字・固有名詞は論文の通りか**:原稿に出てくる数字(対象人数、割合、年齢など)や固有名詞(手法名、尺度名、機関名など)が、その論文の実際の内容と一致しているか確認してください。少しでも違う場合は、正しい値・正しい表記も併記してください。
3. **論文の結論より強く言い切っていないか**:原稿の書き方が、論文が実際に示した結論よりも断定的・確実であるかのように書かれていないか確認してください。特に、`evidence-db.md` の「研究の限界」に書かれている内容(対象人数が少ない、単独の研究である、横断調査で因果関係を示していない、など)が、原稿の中でも正直に反映されているかを見てください。

指摘は、以下の形式で章ごとにまとめてください。

```
## [章番号] 主張の要約
- 引用元: [論文タイトル / DOI]
- ①実在確認: 済 / 未確認 / NG(理由)
- ②数字・固有名詞: 一致 / 不一致(詳細)
- ③言い切りの強さ: 適切 / オーバークレーム(修正案)
```

問題が見つからなかった章についても、「問題なし」として一覧に含めてください。

対象のテーマ:[例:睡眠の質改善についてのnote(有料販売予定)]
