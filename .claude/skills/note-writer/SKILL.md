# note記事の対話作成 → 下書き保存

タイトル(お題)だけを受け取り、対話で内容を引き出しながら本文を書き上げ、
本人のOKが出たら `note-draft` スキルに渡して note.com の下書きとして保存する。
このスキル自身は note.com を直接操作しない(それは note-draft の役目)。

## 手順

### 1. タイトル/お題を確認する
すでに与えられていればそれを使う。無ければ「どんな記事を書きたいですか?」と聞く。

### 2. 数問インタビューする
一度に全部聞かず、会話の流れで3〜5問程度に絞る。すでに文脈で分かっている
ことは聞き直さない。目安の質問:

- この記事で一番伝えたいことは何ですか?
- ご自身の体験談やエピソードはありますか?(具体的な出来事があるほど良い記事になる)
- 他の同じテーマの記事と違う、あなたならではの視点は?
- 想定読者は誰ですか?(初心者/同業者/顧客 など)
- 文体の希望は?(です・ます調 / だ・である調、長さの目安など)
- **有料noteにしますか?**(無料部分だけ公開し、続きを有料にする構成にするか)

質問は必要な分だけでよい。ユーザーが手短に済ませたそうなら深追いしない。

### 3. 本文を執筆する
集めた回答をもとに、日本語でnote記事の本文を書く。体験談やその人独自の視点を
中心に据え、タイトルと一貫性のある内容にする。

**有料noteにする場合は、無料部分と有料部分の役割を分けて書く:**

- **無料部分**: フックになる導入、共感できる体験談やエピソード、問題提起、
  読者が「なるほど」と思える一般論までを書く。ただし核心の結論・具体的な手順・
  再現できるレベルのノウハウはあえて書かない。最後は「ここから先で具体的に
  どうやったかを書きます」のように、続きへの期待を煽る一文で締める。
- **有料部分**: 無料部分で煽った核心そのもの(具体的な手順、テンプレート、数字、
  実際に使ったスクリプトや言い回しなど)を書く。ここを読めば実際に真似・実行できる、
  という具体性を持たせる。無料部分だけでも一定の満足感はあるが、
  「有料部分にこそ本当に欲しかった情報がある」と感じさせる書き方にする。
- 無料部分の末尾に、単独行で `<<<有料エリアここから>>>` という目印を入れる
  (note-draft スキルがこの目印を見つけて、そこに実際の有料エリアを設定する)。

書いた本文はいったん全文をユーザーに提示する(無料/有料の境目もどこかを明示する)。

### 4. 確認・修正
「この内容で下書き保存してよいか、直したい箇所はないか」を確認する。
修正依頼があれば反映し、OKが出るまで繰り返す。

### 4.5 (有料noteの場合) 価格を提案する
本文の内容が固まったら、価格を提案する。**金額を勝手に決めて進めない**。
以下を踏まえて根拠つきで提案し、ユーザーに確定してもらう:

- 有料部分の分量・具体性(手順書やテンプレートなど再現性が高いほど高め)
- 想定読者が得られる価値(時間短縮・収益化に直結するなど)
- ユーザーが知っている同ジャンルの相場感(分かれば聞く。note全体の目安として
  数百円〜1,000円台が一般的で、専門性・実用性が高いものはそれ以上になることもある、
  という程度の一般論は伝えてよい)

提案例:「本文のボリュームと具体性からすると、○○円前後が妥当だと思います。
似た内容の有料noteの相場感があれば教えてください、それも踏まえて調整します」
のように伝え、ユーザーが金額を確定するまでやり取りする。

**確定した価格は note.com に自動入力しない。** 下書き保存後、公開時にユーザー自身が
note.comの公開設定画面で入力する。理由: 価格入力は「公開に進む」画面の中にあり、
そこまで自動操作を広げると誤操作で公開してしまうリスクが増えるため。

### 5. note-draft スキルに引き継ぐ
OKが出たら、確定したタイトルと本文をそのまま `note-draft` スキルの
`scripts/create_draft.cjs` に渡して note.com の下書きとして保存する
(実行方法は `.claude/skills/note-draft/SKILL.md` を参照)。**公開はしない。**
保存が終わったら下書きのURLをユーザーに伝える。有料noteの場合は、
4.5で確定した価格を「公開時にこの金額を入力してください」と併せて伝える。

事前準備(note.comのログインセッション保存)がまだの場合は、その旨と
`note-draft` スキル側の準備手順をユーザーに案内してから進める。
