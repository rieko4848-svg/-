# スレッズのプロフィール＆アイコン作り

スレッズ×楽天アフィリエイトの流れ(①アカウント作成 → ②伸びている投稿のリサーチ →
③楽天アフィリエイト登録 → ④AIで投稿作成)のうち、**①のあとに使うスキル**。
投稿づくり(④)は `threads-post` スキルの担当。

ゴールは、プロフィールを開いた人が一瞬で
「**誰が・誰に向けて・何を発信しているか**」が分かり、
「フォローしたら自分に得がある」と感じること。
自己紹介は「私はこういう人です」ではなく「フォローした人が何を受け取れるか」を中心に書く。

## 伸びているママアカウントのプロフィールの型

- **名前欄**: 呼び名 ＋ 区切り記号(｜ や 〻 など)＋ 何を発信しているか
  (例の形: `〇〇ママ｜育児の気づき・便利グッズ`)
- **自己紹介(5〜6行)**
  1. 発信内容のひと言、または家族構成(`1y👶×4y👦` のような書き方)
  2〜4. 行頭に絵文字を1つずつ置き、フォローした人が得られることを1行ずつ
  5. 属性・経験・実績を「｜」で区切って並べる
  6. リンクへの誘導(例: 紹介したグッズはこちら👇)

## 手順

### 1. ヒアリング(7問)
次の7つを番号つきでまとめて聞く。「答えにくいものは『おまかせ』『なし』でOK」と添える。
すでに会話で分かっていることは聞き直さない。

1. 呼び名(ニックネーム)
2. 子どもの人数と年齢(出したくなければ「なし」)
3. 発信ジャンル(育児グッズ／時短家事／暮らし・収納／100均／節約・お得 など)
4. 届けたい相手(0〜2歳の子のママ、共働きで時間がないママ など)
5. 経験・強み(前職、資格、試したグッズの数、続けている年数 など)
6. アカウントの雰囲気(やさしい／シンプル／明るい／ゆるい／きれいめ など)
7. プロフィールに貼るリンク(楽天ROOM など／まだない)

### 2. プロフィールを3案出す
切り口を変えた3案を作る。言い回しが3案でかぶらないようにする。

- **案A 共感型**: ママのしんどさに寄り添う
- **案B お得・便利型**: 知ると得する情報がもらえる
- **案C 人柄型**: 経験や強みで信頼してもらう

各案に次の4つをセットでつける。

- 名前欄
- 自己紹介(そのままコピーして貼れる形。コードブロックに入れる)
- ユーザーIDの候補3つ(半角英数字と `_` `.` のみ)
- この案の狙い(1行)

最後に「どの案がいいですか？ 組み合わせたい部分や直したい言葉があれば教えてください」
と聞き、希望に合わせて整える。OKが出るまで繰り返す。

### 3. アイコンを作る
プロフィールが決まったら「次はアイコンを作りましょう」と伝え、3つ聞く。

1. タイプ
   - A: イラストで作る(顔出し・写真なしでOK)
   - B: 自分の写真をもとにイラスト風にする(写真を送ってもらう)
   - C: 自分で撮った写真を使う(撮り方のコツを伝える)
2. 好きな色・雰囲気(ベージュでナチュラル、水色でさわやか など)
3. 入れたい要素(子どもと一緒、キッチン、ベビーグッズ、スマホを持っている など)

**A・Bの場合**: このスキルでは画像を直接作れないので、ChatGPT や Canva などの
画像生成にそのまま貼れる**画像生成プロンプト**を書いて渡す。条件は次のとおり。

- 正方形(1:1)
- 丸く切り抜かれても、人物や主役が中央に収まる構図
- 背景はシンプルにし、文字は入れない
- スマホの小さな表示でも何のアカウントか分かり、決めたプロフィールと雰囲気がそろう絵柄
- 子どもを入れるなら、後ろ姿やシルエットなど顔が分からない描き方
- Bなら、写真の髪型や服の色などの雰囲気は残しつつ、本人だと特定されすぎないやわらかいイラストにする

渡したあと「色・表情・ポーズ・背景など変えたいところはありますか？」と聞き、プロンプトを直す。
無料版ChatGPTは1日に作れる画像の枚数に上限があることも一言伝える。

**Cの場合**: 画像は作らず、スマホで撮るコツを5つ以内で伝える
(窓際の自然光／白やベージュの壁を背景に／顔を出したくなければ横顔・後ろ姿・手元だけ／
丸く切り抜かれても中央に収まるように、など)。
子どもが写るなら、顔が分からない撮り方にするよう必ず伝える。

### 4. 仕上げ
スレッズの「プロフィールを編集」から、名前・自己紹介・リンク・写真を設定すれば完成と伝え、
次のチェックを一緒に確認する。

- [ ] 名前欄で「何を発信しているアカウントか」が分かる
- [ ] 本名・住んでいる地域・子どもの名前が入っていない
- [ ] やっていない実績や数字が入っていない
- [ ] 「プロフィールを編集」から名前・自己紹介・写真を設定した

次は伸びている投稿のリサーチ → 楽天アフィリエイト登録 → `threads-post` で投稿づくり、と案内する。

## 守るルール

1. 自己紹介は150文字以内、名前欄は30文字以内を目安にする
2. 絵文字は各行の頭に1つ程度。多用しない
3. ユーザーが答えていない実績・数字・資格は作らない。盛らない
4. 本名・地域・勤務先・子どもの名前など、個人が特定できる情報は入れない
5. 「必ず」「絶対」「治る」など、言い切りすぎや効果を断定する表現は使わない
6. Amazonアソシエイトも使う場合は、Amazonのアソシエイトとして収入を得ている旨の一文が
   プロフィールに必要なことを最後に一言添える
