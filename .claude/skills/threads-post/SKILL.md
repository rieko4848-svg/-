# 伸びている投稿から、楽天アフィリエイトのスレッドを作る

スレッズ×楽天アフィリエイトの流れ(①アカウント作成 → ②伸びている投稿のリサーチ →
③楽天アフィリエイト登録 → ④AIで投稿作成)のうち、**④で使うスキル**。
プロフィール作り(①)は `threads-profile` スキルの担当。

## 考え方

知らない人がいきなり貼った商品リンクからは、誰も買わない。だから気持ちを順番に動かす。

1. **親投稿**: 商品名を伏せて「え、なにそれ？」と手を止めさせる
2. **リプ欄(自分への返信)**: 続きが気になった人にだけ、中身を渡す
3. **リプ欄の最後**: そこで初めて、リンクを1本だけ置く

伸びている投稿からまねるのは**構成と型だけ**。文章や言い回しはまねない。

## 手順

### 1. 参考にする投稿を受け取る
伸びている投稿のスクリーンショットを送ってもらう。
親投稿だけでなく、リプ欄やコメント欄も写っていると分析の精度が上がること、
複数枚でもいいことを伝える。

### 2. なぜ伸びているかを分析する
届いたら、すぐに投稿を作らない。まず次の5点を短くまとめて見せる。

1. 1行目の型(誰に話しかけているか／どこが意外か／何を伏せているか)
2. 親投稿の構成と文字量
3. 商品名を出すタイミング(親投稿か、リプ欄か)
4. 読み手の悩み(コメント欄からうかがえる本音も含めて)
5. ほかの商品にも使い回せる部分はどこか

スクショから読み取れないことは推測で埋めない。

### 3. 3つ質問する
1. アカウントのジャンル(子育て／時短家事／節約／在宅ワーク など)
2. 紹介したい商品は決まっているか
   - 決まっている: 商品名と、実際に使っていれば「いちばん助かっている場面」をひと言で
   - 決まっていない: 「提案して」とだけ答えてもらえばOK
3. 読んでほしい人(例: 未就学児がいて、朝の支度に追われているママ)

### 4. (「提案して」の場合)商品を5つ提案する
分析した型と相性のいい商品を5つ。それぞれに次の4点をつける。

- 商品の種類(何の悩みを解決するものか分かる書き方で)
- 楽天市場で探すときの検索キーワード
- この型と相性がいい理由(1行)
- 親投稿1行目のイメージ(1行)

特定の商品名・ブランド名・価格・在庫・ランキングは、実在を確認できないので書かない。
最後に「どれにしますか？ 楽天で実際に選んだ商品名も教えてください
(商品ページのスクショでもOK)」と聞く。

### 5. スレッドを作る
商品が決まったら、参考投稿と同じ型で次の4本を作る。各投稿はそのまま貼れるよう、
1本ずつコードブロックに入れて出す。

**親投稿(3案)**
- 参考投稿の1行目の型を使う。ただし文章・言い回しは流用しない
- 商品名もリンクも出さない
- 1行目は「話しかけている」「ちょっと意外」「最後まで読まないと答えが分からない」の3つを満たす
- 2行目以降で、その商品に出会う前の困りごとを、生活の場面が浮かぶように具体的に書く
- 最後はリプ欄に目を向けさせるひと言で締める
- 3案は切り口を変える: ①失敗・後悔から入る ②家族や他人のセリフから入る ③常識をひっくり返す

**リプ①**: ここで初めて何の商品かを明かし、何がどう変わったかを具体的な場面で3つ書く

**リプ②**: 正直なデメリットや向いていない人を1〜2個書き、それでも選んでいる理由を書く
(良いことだけにしない)

**リプ③(リンク投稿)**: 「どこで買えるの？」と聞かれた体で入り、
`［ここに楽天アフィリエイトのリンクを貼る］` と貼る位置を明記し、見える位置に `#PR` を入れる

出し終えたら「気に入った親投稿の番号を教えてください。その案に合わせてリプ欄を整えます」と聞き、
選ばれた案に合わせてリプ①〜③を調整する。

### 6. 投稿前の確認を伝える
- 参考にした投稿とまるっきり同じになっていないか、自分の目で確かめる
- きれいすぎる言い回しや違和感のある部分は、自分の言葉に直す
- リンク投稿には必ず `#PR` を入れる(報酬をもらう紹介は広告になるため)
- リンクを貼るのは自分の投稿だけ。他人の投稿のコメント欄には貼らない
- 楽天アフィリエイトの「サイト情報」にスレッズのアカウントを登録しておく
  (未登録のアカウントからの成果は無効になることがある)
- 使ったことのない商品は「使ってよかった」と書かず「気になっている」と書く

## 出力のルール

1. 1投稿500文字以内。読みやすい位置で改行し、1行を長くしすぎない
2. 「【まとめ】」「タイトル：」のような見出しを本文に入れない。そのまま貼れる状態で出す
3. 絵文字は1投稿あたり0〜2個まで
4. リンクはリプ③の1か所だけ。親投稿・リプ①・リプ②には貼らない
5. リンク投稿には必ず `#PR`(ステマ規制で、広告と分からない見せ方は法律で禁止されている)
6. 価格・ポイント倍率・セール情報は変わるので、具体的な金額や「今だけ半額」などは書かない
7. 健康・美容系でも「治る」「痩せる」など効果を断定する表現は使わない
8. ユーザーが使ったことのない商品なら使用体験を作らず、
   「気になっている」「レビューを見て迷っている」というスタンスで書く
